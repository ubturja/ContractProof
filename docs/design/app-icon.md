# ContractProof app icon

Brand-aligned launcher icon for Android (B2B, readable at small sizes). All artwork is original vector geometry; no third-party or copyrighted assets.

## Master asset

| Property | Value |
|----------|--------|
| File | [`icon-1024.png`](icon-1024.png) |
| Size | 1024×1024 px |
| Format | PNG, sRGB |
| Use | Play Console high-res icon, marketing, export source |

Regenerate raster sizes from the master:

```bash
./scripts/generate-icon-pngs.sh
```

## Visual language

| Element | Spec |
|---------|------|
| Motif | Shield (proof) + document (contract) + green check (verified evidence) |
| Primary | `#1F4E79` — matches [`Theme.kt`](../../composeApp/src/commonMain/kotlin/com/contractproof/core/design/Theme.kt) |
| Background | `#F4F6F8` with soft `#D6E4F0` circle |
| Accent | `#157347` — success / verified only |
| Text | None in launcher icon |

## Adaptive icon (Android 8+)

| Layer | Resource |
|-------|----------|
| Foreground | `androidApp/src/main/res/drawable/ic_launcher_foreground.xml` |
| Background | `androidApp/src/main/res/drawable/ic_launcher_background.xml` |
| Wrapper | `mipmap-anydpi-v26/ic_launcher.xml`, `ic_launcher_round.xml` |

**Safe zone:** Keep critical shapes inside the center **66%** of the 108×108 dp canvas (Android adaptive icon guideline).

## Legacy mipmaps

Pre-API 26 and some OEM launchers use raster mipmaps:

| Density | Size (px) |
|---------|-----------|
| mdpi | 48 |
| hdpi | 72 |
| xhdpi | 96 |
| xxhdpi | 144 |
| xxxhdpi | 192 |

Files: `mipmap-*/ic_launcher.png`, `ic_launcher_round.png` (generated by script).

## Manifest

```xml
android:icon="@mipmap/ic_launcher"
android:roundIcon="@mipmap/ic_launcher_round"
```

## Notifications

FCM uses the application icon by default; no separate notification icon is required for MVP.
